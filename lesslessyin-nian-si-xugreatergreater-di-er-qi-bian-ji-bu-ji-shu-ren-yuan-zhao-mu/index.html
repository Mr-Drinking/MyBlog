《鄞年・思叙》第二期编辑部技术人员招募

Mr. Drinking 26/07/07 23:43:01

　　在 5 月 18 日我刊第一期纸质版顺利发放之后，创刊号的工作终于告一段落。而在经过一段时间的休整、计划、讨论之后，编辑部启动了下一期的工作进程。

　　为了适应我部新生代编辑们的实际情况，也为了使我刊能更为有力地弥补创刊号中的不足，我们扩大了编辑部、改变了工作流。而其中自然就包含了对一名乃至数名技术人员的需要。如果你是 25 级与 26 级新生，在阅读本说明后决定加入我们抑或产生了相关意向，请通过 QQ 群号 1079176360 联系我们。

一、工作内容

  • 封面照片拍摄
    • 调色
    • 设计
    • 制作
  • 正文
    • 内页排版
    • 目录设计制作
  • 工作流
    • 稿件录入
    • 上传稿件至 GitHub 仓库
    • GitHub 仓库管理

二、加分项

  • 听说过加一分，实操过加两分，熟练掌握加三分，加粗项在原有基础上额外加一分（下同）：
    • 摄影、调色，Photoshop、Lightroom、Affinity 及其同类，平面设计，InDesign、Illustrator、方正书版、QuantumX、Word、Pages、Google Docs 及其同类，字体排印（Typography），Markdown，OCR 相关工具，GitHub，ChatGPT、Claude、Gemini、Grok 及其同类，Clash、v2Ray、Shadowrocket、mihomo、Xray、sing-box 及其同类
  • 听说过加一分，使用过加两分，拥有中加三分：
    • 像素量能铺满 4961 × 7016（左右）画布的相机，思源宋体（Noto Serif CJK）、思源黑体（Noto Sans CJK）、方正书宋、汉仪书宋二、汉仪旗黑、苹方、霞鹜文楷、朱雀仿宋、方正恒仿宋、San Francisco、Inter、Helvetica、Garamond、Constantia、Noto Serif、Google 账号、外区 Apple ID、带 GMS 的 Android 手机、2019 年及其后发布的 iPhone、搭载 Apple Silicon的Mac(Book)、轻薄型 Windows 笔电、一颗热爱校刊（至少不讨厌）的心、一个宽松且开明的家庭环境
