VPN 全平台教程

Mr. Drinking 25/07/09 03:55:11

作者创作本教程的目的是让更多（他觉得有价值的）人能开阔自己的眼界，提升自己的信息检索能力。因此，本教程的受众应该具备初步数码基础，否则你不适合脱离 GFW 的保护。另外，鉴于教程性质，本人将不介绍其中的原理，具体以后有时间可以在写。 本教程首版作于 2025 年 7 月，鉴于此类教程的特殊之处，作者不保证教程内所述内容长期可用。另外，本教程将不定期更新。

第一步：准备机场节点

准备材料

  • 一台带有正常现代浏览器（如 Chrome、Edge、Firefox、Safari 等，不推荐百度 App、国内安卓手机自带浏览器、360 或 2345 系浏览器等）的任意设备
  • 正常国内网络
  • 电子邮箱
  • 套餐资费（月费数元到数十元不等）

选择机场节点

可以到 GitHub 上去寻找合适的节点，但鉴于中国大陆不稳定的网络环境与此类指南的阅读门槛，作者将推荐三家个人感觉良好的机场服务商，请按需选择。

购买套餐

新用户请先按照网页提示注册账号（但飞鱼加速则不同，需要先购买服务才能注册账号）。随后购买完套餐后，请将您的订阅链接复制到剪贴板中（具体如何操作可以参考网站内教程，不过一般来说自己摸索一下即可）。

Windows 7/8.1 平台
